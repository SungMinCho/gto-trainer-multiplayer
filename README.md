# GTO 홀덤 랩 — 웹 배포본

- `public/index.html`: 앱 전체가 들어 있는 한 파일
- `database.rules.json`: 실시간 데이터베이스 보안 규칙
- `firebase.json`: Firebase Hosting 설정
- `deploy.sh`: 프로젝트 선택부터 배포까지 한 번에 해 주는 스크립트
- `create-db.js`: 프로젝트에 실시간 데이터베이스가 없을 때 `deploy.sh`가 만들 때 쓰는 도우미

## 배포
```
cd ~/repos/holdem-lab
./deploy.sh
```
- 처음 실행하면 내 Firebase 프로젝트 목록이 나와요. 올릴 프로젝트의 번호를 고르면 됩니다. 콘솔에서 직접 만든 프로젝트도 목록에 나와요.
- 고른 프로젝트는 `.project`에 기억돼서, 다음부터는 `./deploy.sh`만 실행하면 같은 주소로 업데이트돼요.
- `./deploy.sh <프로젝트ID 또는 콘솔 이름>`으로 프로젝트를 바로 지정할 수도 있어요.
- 실시간 데이터베이스가 아직 없으면 싱가포르 리전에 자동으로 만들어요. 한국에서 가장 가까운 리전이에요.
- 끝나면 `https://<프로젝트ID>.web.app` 주소가 출력돼요.

## 구조
- 방장 브라우저가 테이블 상태를 관리하고, Firebase 실시간 데이터베이스의 `tables/<코드>/peers`를 통해 모두에게 중계해요.
- 카드는 암호화 셔플(mental poker)로 나눠요. 그래서 데이터베이스도 방장도 다른 사람의 홀카드를 볼 수 없어요.
- 테이블 상태는 `saved/<코드>`에 저장돼요. 모두 나갔다가 다시 들어와도 게임이 이어져요.
- `public/fb-config.json`은 `deploy.sh`가 만드는 파일이에요. 페이지가 어느 데이터베이스에 붙을지를 여기서 읽어요.
